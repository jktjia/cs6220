To use this notebook with [anaconda](https://www.anaconda.com/download/success?reg=skipped), create a conda environment using the following command:

```
conda create --name <env> pandas seaborn anaconda::scikit-learn
```

Then run `homework_1.ipynb` in the conda environment.

Alternatively, run `homework_1.ipynb` in a python environment with the dependencies listed in `requirements.txt`.
